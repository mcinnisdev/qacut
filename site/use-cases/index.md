# Use cases

QACut is one tray icon with three lanes. QACut Basic is a screenshot and a note in seconds, for a person or an AI agent. QACut Bundles turns groups of screenshots and notes into a document or a task list an agent can work from. QACut Studio records the screen and renders a video people will actually watch. Pick the job you have.
