# Privacy policy

Last updated 21 September 2026. QACut is made by Nick McInnis. Questions: [hello@qacut.com](mailto:hello@qacut.com).

The short version: QACut runs on your computer and keeps everything there. It has no account, no analytics and no telemetry. The only thing it ever sends anywhere is a request to GitHub to ask whether a newer version exists.

## The app

**What it stores, and where.** Screenshots, recordings, notes, marks, bundles, exported documents, prompts and settings are written to the `QACut` folder in your user profile (`~/QACut`). They stay there until you delete them. QACut never uploads them.

**What leaves your computer.** Only what you put on the clipboard and paste somewhere else: a screenshot, a file path and note, or a bundle's prompt. Where you paste it, a chat, an email, an AI agent, is your choice, and that service's privacy terms apply to it. Screenshots can contain other people's information; look before you send.

**Checking for updates.** Shortly after it starts, and when you choose **Check for updates...** in the tray, QACut fetches a small file from `github.com` describing the latest release. Like any web request this shows GitHub your IP address and standard request headers, under [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). QACut sends no identifier, no version history and nothing about how you use it. If you install an update, the installer is downloaded from GitHub the same way.

**Microphone and camera.** Off unless you turn them on under **Enable inputs** in the tray. When on, they are recorded into the recording's folder on your computer and nowhere else.

**Keystrokes.** With **Capture keystrokes** on, Studio recordings note which keys were pressed during the recording so they can be shown as badges in the video. That data is written beside the recording and stays there. It is off by default.

**Crash reports and diagnostics.** None are sent. Errors are printed to the app's own log on your computer.

## The website

qacut.com is a static site hosted on GitHub Pages. We set no cookies and run no analytics. GitHub may log requests to the site, including IP addresses, under its privacy statement. Downloads are served from GitHub releases. Links to GitHub, including bug reports and feature requests, take you to GitHub, where anything you post is public.

If you email [hello@qacut.com](mailto:hello@qacut.com), we keep the message so we can reply and follow up. We do not add you to any list.

## Your rights

Because QACut holds no data about you, there is nothing for us to export or delete on request; everything is in your own `~/QACut` folder and your email history. If you believe we hold something we should not, write to [hello@qacut.com](mailto:hello@qacut.com).

## Changes

If this policy changes, the date at the top changes with it, and material changes are noted in the [changelog](/changelog).
